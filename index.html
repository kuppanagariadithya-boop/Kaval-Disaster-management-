Hazard Ingestion

Asterisk Dialplan & Triage Dispatch Engine (Snippet)

; KAVAL Asterisk Dialplan: extensions.conf
[kaval-disaster-broadcast]
exten => s,1,NoOp(--- KAVAL DISASTER DISPATCH: ${CALLERID(num)} ---)
same => n,Answer(500)
same => n,Playback(/var/lib/asterisk/sounds/kaval/flood_alert_${ALERT_LANG})
same => n,Read(CITIZEN_STATUS,custom/dtmf_prompt,1,,2,10)
same => n,GotoIf($["${CITIZEN_STATUS}" = "1"]?safe:eval_risk)
same => n(safe),Agi(kaval_triage.py,${CALLERID(num)},1,SAFE)
same => n,Playback(custom/recorded_safe_ack)
same => n,Hangup()
same => n(eval_risk),GotoIf($["${CITIZEN_STATUS}" = "3"]?med:trap)
same => n(med),Agi(kaval_triage.py,${CALLERID(num)},3,CRITICAL_MEDICAL)
same => n,Playback(custom/rescue_boat_dispatched)
same => n,Hangup()
same => n(trap),Agi(kaval_triage.py,${CALLERID(num)},2,TRAPPED_ELEVATED)
same => n,Playback(custom/rescue_queued)
same => n,Hangup()

Mathematical Signal Model: Goertzel Algorithm

Instead of computing full Fast Fourier Transform (FFT) taking $O(N \log N)$ operations, KAVAL evaluates only the 8 standardized DTMF frequency bins using the recursive second-order Goertzel IIR filter:

1. Feedback Phase: s[n] = x[n] + 2 · cos(2π·k / N) · s[n-1] - s[n-2]
2. Energy Metric: |X[k]|² = s[N]² + s[N-1]² - 2 · cos(2π·k / N) · s[N] · s[N-1]
3. Tone Threshold Validation: |X[k_row]|² > Threshold AND |X[k_col]|² > Threshold AND TwistRatio < 4.0 dB

Viva Voce Defense & Examiner FAQ Cheat Sheet

Top questions asked by college review committees with solid architectural defenses.

Q1 Why voice calls and DTMF over SMS or smartphone apps?

Over 25% of rural citizens in vulnerable flood and cyclone belts cannot read text messages. A ringing voice call produces an immediate auditory and haptic imperative, while keypad DTMF provides guaranteed receipt verification without requiring expensive smartphones or mobile data connections.

Q2 What if cellular towers lose grid power or collapse?

KAVAL deploys a 3-tier fallback: (1) 2G Voice CS-channels operate on battery-backed towers with 8x wider propagation than 4G data; (2) Solar-powered LoRa (868MHz) edge repeaters on elevated municipal hills broadcast synthesized alerts to local village horn megaphones even if all fiber lines are severed.

Q3 How does KAVAL prevent fake or prank "Trapped" acknowledgements?

Three mitigations: (1) Outbound calls target pre-registered electoral/census records; (2) Neighborhood Spatial Triangulation verifies if adjacent households within a 150m radius corroborate the hazard; (3) Priority scoring weights households with registered elderly or infants higher in the triage queue.
